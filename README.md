# ⏱️ FortyMinutesFPS


**FortyMinutesFPS** is a fast-paced first-person shooter built entirely around the concept of a strict time limit. Players have exactly 40 minutes to complete high-stakes objectives, adapt to scaling difficulty, and survive relentless pressure before the clock runs out.

---

## 🚀 Key Features

* **Dynamic Time Management:** Time is both your primary currency and your ultimate enemy. Every second shapes the battlefield.
* **Adaptive Difficulty Scaling:** As the countdown progresses, enemy AI behavior grows increasingly aggressive and tactical.
* **Modular Weapon System:** On-the-fly weapon customization and loadout tweaking to sustain intense combat pacing.
* **Smart Resource Spawning:** An optimized distribution loop that balances ammunition, health, and threat density.

## 🛠️ Tech Stack & Architecture

* **Engine:** Unity 6.5+ (Universal Render Pipeline with Render Graph API)
* **Runtime:** CoreCLR High-Performance .NET Runtime (C# 12+)
* **Input System:** New Unity Input System for cross-platform peripheral support.
* **Patterns:** ScriptableObject-driven architecture for modular gun data, Object Pooling for projectiles/enemies, and Type-Safe State Machines.

## 📦 Installation & Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Open **Unity Hub** and click **Add** -> **Add project from disk**.
3. Select the cloned folder and open it using **Unity 6.5** Editor or newer.
4. Navigate to `Assets/Scenes/` and launch the `MainGameplay` scene.
